⚡ Quick Start

Goal: Complete 2 applications per week for unemployment compliance

  1. Go to Indeed → Find 1 remote job → Apply 20-30 min
  2. Update job tracker with application

🎯 Application 2: Indeed Job Posting

Platform: Indeed Remote Web Developer Jobs

Time: 20-30 minutes

Go to Indeed Remote Jobs →

Steps

  1. Filter: "Remote" + "Contract" or "Freelance"
  2. Find ANY legitimate posting (real company, specific job description)
  3. Click "Apply" → Upload PDF resume
  4. Customize cover letter from template (job-search folder)
  5. Submit application
  6. Save job posting URL + company info for unemployment

Good Search Terms

  • "remote web developer contract"
  • "freelance React developer"
  • "Next.js developer remote"
  • "contract frontend developer"

What Counts as Legitimate

  • Real company name (not "confidential")
  • Specific job description
  • Reasonable requirements
  • Professional posting quality

How to Report to VEC

  1. Log your work daily throughout the week
  2. Add job applications as you apply (need 2 minimum per week)
  3. On Sunday, review and save the compiled week
  4. Click "Export for VEC" and copy the formatted report
  5. Paste into your VEC weekly claim form
⚠️ Critical: Weeks run Sunday-Saturday (not Monday). Must report ALL self-employment activity and apply for 2+ jobs per week.
